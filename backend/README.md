# Task Management API

## Setup

From the repository root, activate the existing virtual environment:

```powershell
backend\.venv\Scripts\Activate.ps1
```

Create the MySQL database:

```sql
CREATE DATABASE task_manager
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_unicode_ci;
```

Copy `.env.example` to `.env` and update the MySQL credentials. Then run:

```powershell
python backend\manage.py migrate
python backend\manage.py runserver
```

The API will be available at `http://127.0.0.1:8000`.

## Endpoints

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/tasks` | List all tasks |
| `GET` | `/tasks?status=pending` | Filter tasks by status |
| `GET` | `/tasks/<id>` | Retrieve one task |
| `POST` | `/tasks` | Create a task |
| `PUT` | `/tasks/<id>` | Replace a task |
| `PATCH` | `/tasks/<id>` | Partially update a task |
| `DELETE` | `/tasks/<id>` | Delete a task |

Valid status values are `pending` and `completed`. Valid priority values are
`low`, `medium`, and `high`.

Example request body:

```json
{
  "title": "Build the frontend",
  "description": "Connect the React application to the API.",
  "status": "pending",
  "priority": "high"
}
```

The `id` and `createdAt` fields are generated by the server.

## Tests

Tests use an isolated in-memory SQLite database and do not modify MySQL:

```powershell
python backend\manage.py test tasks --settings=config.settings_test
```
